# 📜 Índice General de Scripts C#

## 🔑 Autenticación y Servicios Nube (UGS)
* [[scrips/AuthUIController]] - Controla la UI de Login, registro e inicio de sesión.
* [[scrips/UGSAuthManager]] - Maneja la autenticación y sesiones de Unity Gaming Services.
* [[scrips/UGSCloudCodeManager]] - Ejecuta funciones en la nube (Cloud Code) sin MonoBehaviour.
* [[scrips/UGSEconomy]] - Administra las monedas, gemas y transacciones de economía.
* [[scrips/UGSProfileManager]] - Gestiona la información y datos del perfil de usuario.
* [[scrips/UGSRemoteConfig]] - Recupera parámetros y variables de configuración remota.
